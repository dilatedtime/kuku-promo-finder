# Assumptions and scope

1. Timestamps are episode-relative. Episodes play in numeric order. A segment is `[start, end)`, so content beginning exactly at the end is excluded.
2. Exact source time labels define permissible cuts. The tool does not infer frame rate, invent missing boundaries, retime footage or edit video.
3. Overlapping camera, sound, action and dialogue tracks describe simultaneous content. Their durations do not add together. Overlapping dialogue is retained and reported as a source issue.
4. A complete spoken hook must start and finish within the first three seconds. Source prose gives weaker timing evidence for visual actions. Video review is required for those.
5. A line boundary can still split a sentence. Refined retrieval rejects ellipsis-led dialogue openings and penalizes very short replies, but it cannot solve every context gap.
6. Continuous clips are the default. Same-episode stitches are experimental, chronological and require a common speaker. Cross-episode stitches are accepted by the validator but are not generated by this version.
7. Every input episode is searched. The shortlist budget is a configurable limit on model work, not a claim that every worthwhile promo has been found. The ranking does not force one output per episode.
8. Scores are editorial opinions. Neither timestamp validity nor agreement between models measures whether an ad will earn views, installs or subscriptions.
9. The opening three episode loglines provide a limited show premise for a separate representation score. They are not a complete character bible. Primary clip judgment and the cold-viewer pass receive no show context.
10. A human editor checks the highest-ranked clips against video, approves hook/cut timing and rejects misleading context or spoilers. A practical starting review is the top 10, followed by a 24-clip text review sample.
11. The supplied screenplay, private reports, model requests and review transcripts are confidential. Publish code and synthetic fixtures only. No remote inference was used for the submitted pack runs.
12. TXT/MD, normalized JSON/CSV and SRT need explicit timestamps and episode identity. DOCX and PDF imports are limited to extractable text. Ambiguous or malformed inputs fail with a message; there is no silent guessed conversion.
13. The primary free path is local inference on existing hardware. API cost is zero; electricity, hardware and download time are not zero. Remote model adapters are optional and do not promise a provider's free quota.
14. No reference style implies predicted performance. This version follows the brief's hook, unresolved ending and standalone-clip criteria. It has not been validated against a labelled collection of ReelShort or DramaBox ads.
